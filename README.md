# Prosta aplikacja: wpisywanie i usuwanie tekstu

Plik `index.html` zawiera prostą stronę, gdzie możesz wpisać tekst, dodać go pod nagłówkiem i usuwać pojedyncze wpisy.

Jak uruchomić:

1. Otwórz plik `index.html` w przeglądarce (np. dwuklik lub `File → Open`).
2. Wpisz tekst w polu i kliknij `Dodaj` lub naciśnij `Enter`.
3. Aby usunąć wpis, kliknij przycisk `Usuń` obok wpisu.
